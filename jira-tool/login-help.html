❓ Como Usar a Ferramenta Jira Tool V2

← Voltar

📖 Bem-vindo!

Esta ferramenta ajuda os QAs a criar, mover e alterar o status de cenários de teste no Jira em lote, sem precisar fazer tudo manualmente uma issue por vez.

Você não precisa saber programar! É só seguir os passos. 🙂

🔐 1. Autenticação e Segurança

Como Fazer Login

  1. Acesse a página de Login
  2. Digite seu Email pessoal (o que você usa nesta ferramenta)
  3. Digite sua Senha pessoal
  4. Clique em "Entrar"

Primeira Vez? Faça Cadastro

Se é a primeira vez, clique em "Quero me cadastrar" e preencha:

  • Nome: seu nome completo
  • Email pessoal: seu email de login nesta ferramenta
  • Senha: uma senha forte (mínimo 6 caracteres)
  • Email Jira: o email que você usa na API do Jira
  • Token Jira: seu token da API do Jira (veja abaixo como gerar)
  • Domínio Jira: o endereço do seu servidor Jira (padrão: nimbi-portal.atlassian.net)
🔒 Segurança: Seu token do Jira é criptografado e armazenado no servidor. Nunca é exposto no navegador ou em DevTools.

Como Gerar um Token do Jira

  1. Acesse: https://id.atlassian.com/manage-profile/security/api-tokens
  2. Clique em "Create API token" (Criar token de API)
  3. Dê um nome, ex: Ferramenta QA
  4. Clique em "Create" (Criar)
  5. Copie o código que aparecer (é a única vez que você verá!)
  6. Cole aqui no cadastro
⚠️ Aviso: Nunca compartilhe seu token com ninguém. É como uma senha da API.

⚙️ 2. Gerenciar Seu Perfil

Depois de fazer login, clique em "⚙️ Perfil" no canto superior direito para:

Atualizar Suas Credenciais do Jira

  • Email Jira: mude o email que você usa na API
  • Domínio Jira: mude o servidor Jira (se sua empresa usar outro)
  • Novo Token Jira: troque seu token por um novo se perdeu ou por segurança

Para fazer qualquer alteração, você precisará confirmar com sua senha pessoal por segurança.

Mudar Sua Senha Pessoal

Na página de perfil, clique em "🔐 Mudar Senha" (seção Segurança):

  1. Digite sua senha atual (validação)
  2. Digite uma nova senha forte (mínimo 6 caracteres)
  3. Confirme a nova senha novamente
  4. Clique em "Mudar Senha"

💡 Dica: Use senhas com letras, números e símbolos para maior segurança.

➕ 3. Criar Cenários

Na aba "➕ Criar Cenários", você pode criar vários cenários de teste de uma vez.

Preencher os Campos

  • Issue Pai (História): a chave da história, ex: COR-10179
  • Tipo de Issue: normalmente Subtask de teste (deixe como está)
  • Status Final: o status final que os cenários devem ter após criar

Escrever os Cenários

A ferramenta aceita vários formatos. Exemplos:

Formato Estruturado:

CT-01: Login com email e senha
Pré-condição:
Usuário não autenticado
Ação:
Digitar email
Digitar senha
Clicar em "Entrar"
Resultado Esperado:
Usuário autenticado e redirecionado para home

Formato Gherkin:

Cenário: Filtro avançado funciona
Dado que estou na tela de Minhas Conexões
Quando clico em "Filtros Avançados"
Então os filtros aparecem na tela

Pré-visualizar e Criar

  1. Cole seus cenários no campo de texto
  2. Clique em "🔍 Pré-visualizar" para ver como serão criados
  3. Se estiver certo, clique em "Criar Cenários"
  4. Aguarde a ferramenta processar (pode levar alguns segundos)

💡 Dica: Você pode copiar/colar os cenários de um documento de Word, Google Docs, etc.

📦 4. Mover Cenários

Use esta aba para vincular/desvinculador cenários de uma história para outra.

Como Funciona

  1. Digite a História Origem (onde os cenários estão agora)
  2. Clique em "🔍 Buscar Issues" para listar os cenários
  3. Selecione quais cenários quer mover
  4. Digite a Nova História Pai de Destino
  5. Clique em "Mover Cenários Selecionados"

💡 Dica: Se tem muitos cenários, use o filtro de status para encontrar mais rápido.

🔄 5. Alterar Status

Mude o status de vários cenários de uma vez sem clicar em cada um individualmente.

Como Funciona

  1. Escolha como quer buscar os cenários:
    • Por História: digite a chave da história e a ferramenta lista todos os cenários dela
    • Por Lista: cole as chaves dos cenários diretamente (ex: COR-10236, COR-10237)
  2. Escolha o Status Alvo (para onde quer mover)
  3. Clique em "Buscar" para listar os cenários
  4. Selecione quais quer alterar (ou "Selecionar Todos")
  5. Clique em "Alterar Status"
ℹ️ Nota: A ferramenta segue a mesma sequência de transições de status que o Jira. Se não conseguir ir direto para um status, você pode ter que passar por status intermediários.

🔒 Perguntas Frequentes de Segurança

Meu token do Jira é seguro?

Sim! Ele é criptografado com AES-256-GCM e armazenado no servidor. Nunca aparece no seu navegador ou em DevTools.

Posso recuperar um token que eu perdi?

Não é possível recuperar o token antigo. Se perdeu, você deve gerar um novo em id.atlassian.com e atualizar na página de Perfil.

Se eu colocar um novo token, o antigo continua funcionando?

Não. Quando você salva um novo token aqui, o antigo é imediatamente descartado e você precisa usar o novo.

Quem pode ver meu token?

Ninguém. O administrador da ferramenta não pode ver. Fica criptografado no banco de dados.

E se eu esquecer minha senha pessoal?

Nesta versão, você precisa entrar em contato com o administrador para resetar sua conta. Em futuras versões, pode haver opção de recuperação por email.

A ferramenta expõe dados no DevTools?

Não. O token nunca é enviado para o navegador. Fica armazenado no servidor e é usado lá mesmo para comunicar com o Jira.

✅ Segurança Garantida: Você pode inspecionar o DevTools que não vai encontrar token ou dados sensíveis lá. Todos os dados sensíveis ficam no servidor.

❓ Dúvidas Gerais

Como alterar meu nome ou email pessoal?

Por enquanto, essas mudanças precisam ser feitas pelo administrador. Entre em contato.

Posso usar a ferramenta em vários computadores?

Sim! Você pode fazer login de qualquer computador com navegador. Sua conta e dados estão no servidor.

A ferramenta funciona com múltiplos Jiras?

Nesta versão, você usa um Jira por conta. Se precisar trocar de Jira, atualize os dados na página de Perfil.

Quantos cenários posso criar de uma vez?

Tecnicamente, vários! Mas recomendamos não más de 50-100 por vez para evitar travamentos. Se tem muitos, divida em lotes.

Posso voltar/desfazer uma ação?

Não. As mudanças são imediatas no Jira. Sempre revise a pré-visualização antes de criar!

🆘 Problemas?

Se algo não funcionar:

  1. Verifique sua conexão com a internet
  2. Tente fazer logout e login de novo
  3. Limpe o cache do navegador (Ctrl + Shift + Delete)
  4. Teste em outro navegador (Chrome, Edge, Firefox, etc.)
  5. Se o erro persistir, anote a mensagem de erro e avise o administrador

Mensagens de Erro Comuns

"Credenciais inválidas":

  • Email ou senha do Jira estão errados
  • Verifique o email exato que você usa na API do Jira
  • Regenere o token se suspeitar que expirou

"Não autenticado":

  • Sua sessão expirou
  • Faça login novamente

"Erro ao criar cenários":

  • Verifique se a História Pai (Issue Key) existe no Jira
  • Confira se a chave está no formato correto (ex: COR-10179)
  • Tente criar um cenário manualmente no Jira para testar se tem permissão
